# Arraial do Pavulagem

Site de apresentação do Arraial do Pavulagem, com informações sobre a história do
grupo, o cortejo e uma galeria de registros.

## Estrutura

```
Projeto-Arraial-do-Pavulagem/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   └── img/
│       ├── logo.png
│       ├── Banner.jpg
│       ├── Screenshot_20240612-114611.png
│       ├── 173013695_d37c8a5d16_b.jpg
│       └── 7fc07c5f-b013-489b-b5bc-7c26be4a623d.webp
└── .vscode/
    └── settings.json
```

## Como rodar

1. Instale a extensão **Live Server** no VS Code.
2. Abra a pasta `Projeto-Arraial-do-Pavulagem` como raiz do workspace.
3. Clique com o botão direito em `index.html` e escolha **Open with Live Server**.

A porta padrão está configurada para `5501` em `.vscode/settings.json`.
