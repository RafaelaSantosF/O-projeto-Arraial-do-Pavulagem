# Arraial do Pavulagem

Site de apresentação do Arraial do Pavulagem, com informações sobre a história do
grupo, o cortejo e uma galeria de registros.

## Estrutura

```
O-projeto-Arraial-do-Pavulagem/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   └── img/
│       ├── ARRAIAL-DO-PAVULAGEM-1_00806997_1_.jpg
│       ├── Banner.jpg
│       ├── Ceu-da-Camboinha.jpg
│       ├── Historia.png
│       ├── Logo.jpg
│       ├── Registro.jpg
│       ├── Registro.png
│       └── Registro.webp
└── .vscode/
    └── settings.json
```

## Como rodar

1. Instale a extensão **Live Server** no VS Code.
2. Abra a pasta `O-projeto-Arraial-do-Pavulagem` como raiz do workspace.
3. Clique com o botão direito em `index.html` e escolha **Open with Live Server**.

A porta padrão está configurada para `5502` em `.vscode/settings.json`.
